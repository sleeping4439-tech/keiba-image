ゆ馬録 クラウド対応版 / 導入手順

1. Supabaseで自分用プロジェクトを作成。
2. SupabaseのSQL Editorで yubaroku_supabase_setup.sql を実行。
3. Authentication > Users で自分のメールアドレスのユーザーを作成（または招待）。公開サインアップは無効化を推奨。
4. Project URLとPublishable key（旧anon keyも可）を控える。secret key / service_role keyは絶対にブラウザに入力しない。
5. yubaroku_cloud.html をGitHub Pages等のHTTPS固定URLで公開（index.htmlにリネーム可）。
6. 「クラウド設定・ログイン」でURL・公開キー・自分のメールアドレス・パスワードを入力。
7. 最初のログイン後、クラウドに既存データがなければローカル下書きが残る。「クラウドに保存」で初回アップロード。
8. 2台目は同じURLを開き、同じアカウントでログインして「クラウドから読込」。
9. 編集後は「クラウドに保存」を押したときだけサーバーを更新。JSONとCSVの書き出しも可能。

注意:
・このファイルを開いただけではクラウド保存は有効になりません。Supabase設定が必要です。
・ローカル下書きはブラウザに保存されます。クラウドへの送信は保存ボタンを押した時だけです。
・別端末で同時に変更した場合、古い版からの保存は拒否されます。先にJSONバックアップを書き出してください。
・クラウドから読込はローカル下書きを置き換えます（差異があれば確認します）。
・JSONの読み込みはローカル下書きの置き換えです。クラウドへ反映するには別途「クラウドに保存」を押してください。
・Supabase認証とRLSにより本人のみアクセス可能な設計です。アカウントや鍵の管理は必要です。
・定期的にJSON/CSVを手元に保存してください。
・この成果物はまだGitHubに公開していません。
